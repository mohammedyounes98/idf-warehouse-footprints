# Data licence

## Status

This dataset is released as a **public working dataset (v0.1.0)**.

It is a derived geospatial database produced from multiple upstream data sources with distinct licences and attribution requirements. A final consolidated licence will be assigned in a future release following a complete compatibility review.

Until then, this dataset is made available under the following **interim conditions of use**.

---

## Permitted uses

You may:

- use the dataset for research, exploratory analysis, and visualisation;
- create derived works and analyses;
- include the dataset in academic publications and reports;

provided that you comply with the attribution and redistribution conditions below.

---

## Attribution requirements

Any use of this dataset must include:

1. **Dataset citation (mandatory)**  
   Mohammed Younes (2026). *Working inventory of large warehouse footprints in Île-de-France, France* (v0.1.0). Zenodo. https://doi.org/10.5281/zenodo.19131942

2. **Upstream source acknowledgement (mandatory)**  
   See `NOTICE.md` and `docs/sources-and-attribution.md`.

At minimum, attribution should include:

- OpenStreetMap contributors  
- Copernicus Land Monitoring Service (CORINE Land Cover)  
- IGN (where applicable)

---

## Important note on OpenStreetMap (ODbL)

Part of this dataset is derived from OpenStreetMap data.

OpenStreetMap is licensed under the **Open Database Licence (ODbL)**, which may impose obligations on redistribution of derivative databases.

Users intending to:

- redistribute this dataset,
- integrate it into another database,
- or publish derived datasets,

must ensure compliance with ODbL requirements where applicable.

Refer to:
https://osmfoundation.org/wiki/Licence
