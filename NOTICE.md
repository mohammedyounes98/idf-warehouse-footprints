# Notice and attribution

This repository contains a public working release derived from a broader geospatial processing workflow that relies on multiple upstream data sources.

Users of this release must preserve the relevant source acknowledgements in any redistribution, derivative work, or publication based on the dataset.

At minimum, the release documentation should acknowledge the following upstream source families where applicable:

- OpenStreetMap contributors
- Copernicus Land Monitoring Service / CORINE Land Cover
- IGN datasets used in the internal processing workflow
- Any additional public source explicitly listed in the release documentation

This notice file is provided to ensure that attribution obligations are not lost when the dataset is copied, redistributed, or cited elsewhere.

A fuller source statement may be added in later releases once the release documentation and licensing review are finalised.
